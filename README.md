# PHP Login System

Sistema simples de login em PHP usando:

- Session
- Cookie
- LocalStorage

## Tecnologias

- PHP
- HTML
- CSS
- JavaScript

## Funcionalidades

- Login
- Logout
- Sessão
- Cookie
- LocalStorage

## Usuário de teste

```txt
Usuário: admin
Senha: 1234
```

## Estrutura

```txt
index.php
pages/
 ├── login.php
 └── logout.php
```

## Como executar

Use:

- XAMPP
- WAMP
- Laragon
- PHP Server

Abra:

```txt
http://localhost/
```
